# 🏨 Hotel Booking System

A web-based hotel booking application created for the Web Technology course. It provides a simple and user-friendly platform for customers to book hotel rooms and an admin panel to manage operations.

### ✨ Key Features

- **Client Panel:**
  - Search hotels and browse available rooms
  - Room booking form with input validation
  - Payment and booking confirmation screens
  - User Sign-up & Login pages

- **Admin Panel:**
  - Dashboard with overview metrics
  - Manage rooms (add, edit, view status)
  - Track guest bookings and records
  - View reports and summaries

### 🛠️ Built With
- **HTML5** – Page structure and semantic layout
- **CSS3** – Responsive styling and design
- **JavaScript** – Form validation and interactive UI
